## B. 写作工作台（Phase 6a）

- [ ] 打开工作台：四个页签 **章节 / 资料库 / 关系图 / 统计**，底部栏 49dp 不透明、选中项为强调色
- [ ] 章节页：作品 → 卷 → 章节三级分组；行显示状态、字数、日期
- [ ] 章节行**左滑**露出「移动 / 改名 / 删除」三个动作
  - [ ] 移动：底部抽屉选目标卷，移完章节出现在目标卷末尾
  - [ ] 改名：输入框改标题，正文不受影响
  - [ ] 删除：二次确认后章节与正文一起消失
- [ ] 资料库页：八类资料分组，颜色图标区分；无资料时显示空态
- [ ] 统计页：三张数据卡（总字数/章节数/近 7 天）+ 概况分组
- [ ] 点章节进入编辑页：正文 19/32 显示，底部工具条有字数/字号/护眼/大纲/润色
  - [ ] 编辑后点「保存」，重新进入内容一致
  - [ ] 系统返回键先关编辑页、再关工作台

## C. 人物关系图 v2（Phase 6b · 2026-11-08 按「Minis 持平」重写）

> 入口：**设置 → Agent Runtime 组末「关系图」行**（不是工作台页签——写作 UI 整体未落地，
> 本块按 UI_SPEC §0「完全沿用 Minis 界面布局」做成设置内的两级页面）。
> 视觉规范：UI_SPEC §5.8；实现：分支 `feature/graph-v2-ui`。

- [ ] 打开「关系图」：先看到**作品列表**（iOS 分组列表：uppercase 标题 + 圆角卡片 + chevron），无作品时给引导空态
- [ ] 选一部作品进入画布：底色为页面底色（亮 #F2F2F7 / 暗 #000），**无卡片堆积、无 Material tonal 染色**
- [ ] 节点是 `cardSurface` 圆形（直径 56dp）+ 1dp 描边 + 外圈角色色弱环；姓名以 subhead 置于节点下方
- [ ] 边按**关系类型**取八类调色板（亲人=蓝 / 恋人=靛 / 师徒=青 / 盟友=绿 / 竞争=红 / 仇敌=橙 / 上下级=紫 / 其他=灰），不透明度 60%
- [ ] 边的粗细随 `strength` 变化（1→1dp、2–3→2dp、4→3dp、5→4dp）；强度高的边上显示关系名
- [ ] 无选中时全部边标签都显示；**边标签不糊成一团**（短名截断 + 只画在边中点）
- [ ] 单指拖动可平移画布；双指捏合可缩放（范围 0.4x–3x，且不跟平移打架）
- [ ] 点节点：其邻边升至 100% 不透明度 + 6dp 模糊光晕，其余节点与边淡出，底部弹出详情面板
- [ ] 详情面板列出该人物的所有关系（对端名 · 类型 · 强度），超过 8 条显示「还有 N 条」
- [ ] 再点同一节点或空白处取消选中，图恢复全亮
- [ ] 顶部统计条显示「N 位人物 · M 条关系」；只有 1 位人物时提示「只有一位人物，暂无关系可显示」
- [ ] 关系数据为空时画布显示空态引导（不是白屏/崩溃）
- [ ] 力导向布局在 3–5 秒内收敛静止（帧循环自动停，不持续耗电）
- [ ] 旋横屏 / 分屏后重新布局不崩、节点不出屏
- [ ] 切到系统深色模式：画布底色、卡片面、节点描边、边色全部跟随反转
- [ ] 退回作品列表再进另一部作品，画布是该作品的数据（不是上一部的残留）

## D. 模型组 / 写作档（Phase 6.5）

- [ ] 设置 →「写作 → 模型组」打开列表页；预置三档（默认写作组 / 轻量组 / 审查组）
- [ ] 新建组 → 进入详情 → 改名称 → 保存
- [ ] 添加模型：选 provider → 拉取该 provider 的模型列表 → 选中加入
- [ ] 组详情可改角色（普通/默认组/轻量组），列表页徽标随之变化
- [ ] 「子代理模型」页：6 个子代理（大纲/人物/伏笔/润色/审读/一致性）各自可选组
- [ ] 委派行为验证（关键）：
  - [ ] 给某子代理钉一个组 → 触发该子代理的委派 → 结果 JSON 里 `model_used` 显示该组与模型
  - [ ] 不钉组时，委派请求带 `model_group=default_model` → 走默认组
  - [ ] 把钉的组成员删空（组不可用）→ 委派结果里出现 `model_group_unavailable: true` 与回落说明
- [ ] 删除组后，指向它的子代理绑定被解除（显示"跟随委派请求"）
